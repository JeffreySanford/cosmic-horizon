Jobs View Summary

This view is the operational launch and monitoring console for AI-assisted radio astronomy jobs. It captures science intent, submits jobs to the configured backend mode, and tracks status to completion.

What Happens On Submit

  • Form inputs are converted into a structured job payload.
  • The API accepts the submission and returns a canonical job ID.
  • The UI requests optimization tips for the chosen parameters.
  • Polling begins on the job status endpoint until terminal state.

Modes and Backends

  • Demo: simulated behavior for offline validation.
  • Local-LLM: local inference-backed orchestration path.
  • Live: remote execution against approved infrastructure.

How To Use This Panel

  • Define target and observation context before submit.
  • Use filter chips to isolate active failures/running jobs.
  • Inspect details and cancel in-progress runs if needed.
  • Use optimization tips to tune runtime, GPU usage, and RFI policy.

Science Context

For reconstruction scenarios, select ImageReconstruction with appropriate RA/Dec, band, and product goal to generate science-ready image artifacts from calibrated visibility workflows.

Pre-Run Q&A

Ask about runtime, cost, risks, or workflow order before submitting. Answers use your current form values.
